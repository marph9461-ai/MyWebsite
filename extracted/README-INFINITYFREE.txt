HOW TO DEPLOY / خطوات الرفع والتشغيل:
========================================================================
1. Open your InfinityFree Control Panel -> File Manager (Monsta FTP).
2. Navigate into the "htdocs" folder.
3. Upload all files and folders from this package into "htdocs/":
   - index.php
   - about.php
   - shop.php
   - product.php
   - cart.php
   - blog.php
   - post.php
   - contact.php
   - includes/ (data.php, header.php, footer.php)
   - assets/ (css/style.css, js/main.js)
   - .htaccess
4. Visit your site (e.g. yourname.rf.gd). You can switch between English and Arabic instantly!
